# Explicit grouped default-pcurve material repair

`RepairGroupedPCurveOCCTConvexArcExtrusion` promotes the independently authenticated two-fillet default OCCT source through an **explicit repair**, distinct from every exact or single-fillet route. It requires all proofs in `GROUPED_RATIONAL_CAP_EVIDENCE.md` and `GROUPED_CAP_FINITE_TRIMS.md` before returning a solid:

- Complete original root, unit, shell, face, edge, vertex and exclusive pcurve dependency ownership.
- The original grouped model repair's independently selected exact plane/cylinder tangencies, matched circle/edge/two-coedge reversal, and exact reconstructed native model topology.
- Twenty-eight continuous same-parameter owner lift bounds, including opposite cylindrical U speed for the reversed circular models.
- Two rational cap curves with positive homogeneous denominators, continuous original source spans, strict angular monotonicity and one winding; bounded radial projection to the corresponding original circle; and a uniquely selected first-quadrant finite arc with explicit endpoint bounds and original coedge senses.

The rational cap curves use a **nonlinear reparameterization**. The original source angular CIRCLE parameter and rational B-spline parameter are not equal: independent OCCT observes the approximately 0.0096 same-parameter discrepancy documented in the prerequisite. The repaired material owns exact circular boundaries. `OriginalSTEP` returns the unchanged source with its authoritative pcurves. `CorrectedModelSTEP` is explicitly a model-only corrected graph, and `Descriptor` generates standard exact model-only STEP through `WriteExactCircularLoopExtrusion`; neither claims to rewrite the source UV graph into exact equivalence.

Caller `MaxDistance` independently bounds model repair sites/whole shifted axial supports, the twenty-eight owner discrepancies, the two radial projections and source-vertex-to-selected-cap-endpoint discrepancies. No aggregate source-material Hausdorff bound is asserted. The authenticated shape scope remains two distinct fillets on this five-segment convex profile, five planes and two cylinders, under the original unposed model grammar. Arbitrary curves, arbitrary finite trim branches, grouped posed pcurve source and direct same-parameter rational-cap promotion remain unsupported.

`PCurves`, `RationalCaps`, `FiniteTrims`, `Repairs`, `Reversals`, `Tangencies` and `Provenance` return copied original evidence. Algebraic station objects are immutable. Native persistence uses the distinct version-one tag `plainsolid-step-grouped-pcurve-convex-arc-repair`. Writer and reader independently re-prove the original source and compare all canonical claims, including source roles, model recipe, native bytes, rational bounds, station polynomial/enclosure and reversal evidence. The immutable root is reconstructed from that source proof, never decoded from an untrusted root object. Claims are kept as raw JSON until canonical comparison, avoiding unbounded rational parsing. Old tags and API meanings are unchanged.
