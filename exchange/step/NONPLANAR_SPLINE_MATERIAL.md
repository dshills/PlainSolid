# Unified authenticated nonplanar spline material

`ReadNonplanarSplineMaterial` selects exactly one existing strict source validator from the original STEP body, shell, polynomial carrier and pcurve declarations. It supports the previously qualified quadratic shell, bicubic shell, multispan affine UV shell, common rational boundary-speed shell, one-void and two-to-four-void families. It is not a general spline-solid importer. Rational carriers, mixed roots, unsupported combinations and malformed selected families fail without trying a weaker validator.

The opaque result exposes native material, name, length unit and copied provenance: original body, shell, oriented void, face, support, model edge and pcurve IDs, plus native face indices. Classification is one bounded parse followed by the selected validator's bounded complete proof. Source limits are at most 1 MiB, 2,048 entities, 32,768 values and depth 16; caller limits can reduce them. Existing detailed readers remain unchanged.

`WriteNonplanarSplineMaterialSource` preserves original source bytes after reproof. `WriteNonplanarSplineMaterial` emits independently readable standard polynomial STEP and re-imports it before writing. Generated multispan-UV and rational-speed inputs normalize boundary parameterization and classify as quadratic shells; source-preserving export retains their original parameterization and kind. Material geometry is preserved, not the original parameter speed or all original entity IDs in generated output.

The separate version-1 `plainsolid-step-nonplanar-spline-material` JSON envelope stores original source, classification, metadata, provenance and canonical native geometry. Reload re-proves the original source and compares every stored claim; it does not trust serialized geometry. Older format tags remain separate. Cancellation and bounded input are checked, and validation failure returns no material or emitted prefix.

Six retained independently authored OCCT source fixtures cover all branches. Tests exercise source/native/generated round trips, immutable provenance, changed geometry, incompatible tags, forged ownership, mixed roots and declarations that must not downgrade. The optional live check uses `PLAINSOLID_OCCT_SPLINE_ROOF_VOID` with the comparator built by `tools/occtref/build_author_ap242_spline_roof_void.sh`; source and generated output must transfer as one solid with expected face count and volume. A 60-execution single-worker fuzz campaign covers the six source seeds and malformed input.
