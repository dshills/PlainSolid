# Exact affine planar pcurves in rational hierarchies

`ReadAffinePCurveRationalHierarchy` and
`ReadOCCTAffinePCurveRationalHierarchy` explicitly admit a previously rejected
original OCCT Boolean-cut planar product. The previous hierarchy readers and
native format tags are unchanged.

The retained source was generated by OCCT 4dbfdcc448c0b3e565488afcd626c84483172db9
using a Boolean difference of two boxes. It contains 16 two-pole degree-one
`B_SPLINE_CURVE_WITH_KNOTS` pcurves on authoritative 3D `LINE` edges. It does **not**
contain `TRIMMED_CURVE`; no trimmed-curve support is added here. The independent
local source is `testdata/occt-affine-pcurve-holed-product.step`.
`tools/occtref/author_step_reentrant_hierarchy.py` places its unchanged owned
geometry records into both retained rational AP214 hierarchy conventions.

The supported spline has clamped multiplicities (2,2), two strictly increasing
source knots, no weights, no internal knots, no closed/periodic declaration,
and one nonzero UV derivative component. Its original exact decimal poles and
knots determine an affine function on the full knot interval. After lifting
through its own exact signed-coordinate plane frame, both coefficients must
agree **exactly** with the authoritative model LINE, including its vector
magnitude and original parameter origin. The source knot endpoints must equal
the EDGE_CURVE vertices in the declared same-sense order. A jointly reversed
edge and both original coedge uses is supported; a sense-only mutation fails.

The pcurve spline, its two poles, definitional representation and surface-curve
link must have exclusive ownership along the checked chain. The complete
existing hierarchy/planar proof then validates actual adjacent face ownership,
finite directed loops, holes, closed material topology, embedded boundary,
product closure, occurrence paths, units and exact frame composition. Unknown
or orphan geometry is not erased. This is not generic spline fitting.

A private proof view substitutes an exact untrimmed LINE for each validated
pcurve only after the full finite-interval proof. It reuses exclusively owned
records and adds one vector per spline. The original source text and source
IDs remain distinct and unchanged. `OriginalSTEP` returns that text;
`AffinePCurves` returns copied exact rational coefficients and original IDs.
`ProofHierarchy` returns a fresh caller-owned normalized proof graph, explicitly
not the original authored graph. `LocatePoint` and `ClipLine` preserve original
material face/edge/vertex IDs and occurrence paths, including coplanar hole
intervals. Assembly query results are per occurrence, not a Boolean union.

`Write/ReadAffinePCurveHierarchyJSON` use a distinct version-one envelope with
an explicit neutral-child versus OCCT frame convention. Reload re-proves the
original source and compares all normalized native, coefficient and ancestry
claims. Failed readers return no partial object. STEP input is capped at 1 MiB,
4096 records, 65536 values and depth 16 (caller limits may lower these); existing
hierarchy product/occurrence/depth limits remain. Exact source scalar parsing
bounds token length, exponent and rational coefficient sizes before arithmetic.
The small fixed affine calculation per source record is bounded by those input
limits. Native JSON is capped at 16 MiB; cancellation is checked before parsing,
per source candidate and throughout inherited material proofs.

then run its output as `binary output.step cut-hole`. The stock is
[-10,-6] × [-4,0] × [-2,2], cut by [-9,-7] × [-3,-1] × [-3,3].
Its volume is 48 and its boundary area is 120, independently from elementary
box subtraction (outer surface 96, removed cap area 8, inner wall area 32).

canonical native reload and tamper rejection in both frame conventions.

the authored source graph. It validates every original pcurve again and
retains its original evidence. The `document` adapters expose the edited
source and exact original-loop mass and boundary area; the hole prism keeps
volume 48 and boundary area 120 after the rigid move.

oracle to compare original source and emitted proof-view STEP transfer.
