# Exact canonical eccentric through-bore material

`ReadEccentricThroughCylinderSolid` / `WriteEccentricThroughCylinderSolid` add a
separate type-186 manifold normal form. This is a positive-Z outer circular
cylinder with a displaced parallel circular through opening, not a general IGES
Boolean importer. `BoreOffset` is an explicit represented XY displacement from
`Origin`; zero displacement is rejected and remains the existing coaxial family.

The 37-record graph retains two type-192 supports with independently owned
centers, two type-190 planar caps, six original type-100/type-110 model edges,
type-502 vertices, type-504 edge list, type-508 loops, type-510 faces and the
closed type-514/type-186 shell/solid. Cylinder wall pcurves use exact degree
coordinates 0–360 and the original axial height. Planar cap loops reference
model circles without invented pcurves. Both caps have the outer positive and
inner negative loop; shell signs retain the positive outer/negative inner wall.

The reader checks the entire canonical owner/reference/scalar layout, exact
original-decimal-to-binary representability, per-owner support coordinates and
finite directed loops. The supplied offset is recovered by lossless subtraction
of original support centers. Exact rational arithmetic proves
`dx²+dy² < (outerRadius-innerRadius)²`, with positive radii and positive height.
This is strict containment, not a rounded hypot comparison; touching and
intersecting footprints reject. Every constructed center, radius endpoint and
cap height sum must be losslessly representable. No tolerance changes source
geometry. The existing native raw finite-cylinder difference independently
constructs the material and retains stock/cutter ancestry.

The returned result retains all original directory IDs, scalar parameters and
labels/subscripts. It has one nonempty native component and empty second slot.
Native sewing uses its existing tolerance and may reject unresolved narrow
clearance; this codec does not widen native modeling guarantees. No general
placements, arbitrary source record reordering, blind cuts, partial cylinders,
angular approximation, or generic vendor graph acceptance is claimed. The
writer deliberately authors a new canonical descriptor graph rather than
promising byte-preserving source re-export.

Limits are at most 65536 bytes, 37 entities, 1024 records and 4096 values, plus
stricter caller limits. Cancellation and malformed source failures return no
partial material; writer staging validates the entire graph before any output.
The original coaxial, blind and circular-cylinder APIs are unchanged and reject
this different normal form.
