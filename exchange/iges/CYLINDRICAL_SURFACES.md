# Standalone circular-cylinder supports

`ReadCylindricalSurfaces` / `WriteCylindricalSurfaces` handle IGES type 192,
form 1, with uniquely owned type 116 location and two type 123 direction
entities. `CylindricalSurface.Geometry` returns the existing native analytic
`geom.CylinderSurface`. U is radians measured from the explicit reference ray;
V is signed coordinate distance along the axis. Length units remain explicit
meters per raw coordinate unit, with no coordinate rescaling.

This is an **unbounded support**, with no finite domain, face, shell, solid or
material claim. Form 0 (an unspecified parameter frame), topology entities,
transforms, non-coordinate directions, shared dependencies and unused entities
are rejected. Axis and reference must be perpendicular signed coordinate unit
vectors: no normalization or projection silently changes source coordinates.
Every source numeric scalar must be exactly representable as float64; writer
output is re-read under the same restriction before any caller I/O. Some binary
values whose short decimal spelling is inexact are therefore rejected.

Names and subscripts of the root and all dependencies are retained. The writer
uses canonical subordinate geometry status; the reader additionally recognizes
OCCT's location and direction usage statuses. Presentation styling is not part
of this API. The bounded record parser enforces sections, entity/record/value/
byte limits, pointer ownership and no transformations. There are at most 64
surfaces and 256 total entities. Existing generic and topology readers retain
their previous acceptance rules.

The retained `testdata/cylindrical-surface.igs` fixture is independently authored
using OCCT entity constructors, rather than generated by this Go writer. The
optional `PLAINSOLID_OCCT_IGES_CYLINDER` test uses the dedicated
`tools/occtref/iges_cylinder.cxx` helper to transfer source and Go-authored
supports to OCCT analytic surfaces, then compares points and both partials for
positive and negative X axes with a nondefault radial reference. This verifies
analytic support semantics, not bounded-face transfer or solid validity.
